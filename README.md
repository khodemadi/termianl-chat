# LAN Terminal Chat — TUI

یک چت LAN با رابط ترمینالی واقعی، شبیه Vim / htop / lazygit.

وقتی برنامه اجرا می‌شود، ترمینال وارد یک **Alternate Screen** می‌شود و یک محیط کامل برای چت می‌سازد. با خروج، ترمینال دقیقاً به حالت قبل برمی‌گردد.

## اجرا

```bash
cargo run --release -- Ali
```

روی دستگاه دیگر:

```bash
cargo run --release -- Reza
```

بعد از چند ثانیه کاربران آنلاین در پنل سمت چپ دیده می‌شوند.

## کنترل‌ها

- `↑` / `↓` انتخاب کاربر
- `Tab` جابه‌جایی بین بخش‌ها
- تایپ مستقیم برای نوشتن پیام
- `Enter` ارسال
- `Ctrl+C` یا `q` خروج

## شبکه

- UDP `45454` برای پیدا کردن دستگاه‌ها
- TCP `45455` برای چت
- بدون سرور مرکزی
- فقط دستگاه‌هایی که برنامه را اجرا کرده‌اند در لیست دیده می‌شوند

## نکته

این نسخه برای شبکه LAN قابل اعتماد طراحی شده و هنوز رمزنگاری End-to-End ندارد.
